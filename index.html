Understanding fork and pull request

Git and Github

A fork is a personal copy of someone else's project. It allows you to freely experiment with changes without affecting the original project. When you create a fork, you can make changes to your copy of the repository. Once you are satisfied with your changes, you can submit a pull request to the original repository. A pull request is a way to propose your changes to the original project. It allows the maintainers of the original repository to review your changes and decide whether to merge them into the main branch of the repository.
